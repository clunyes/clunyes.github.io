rxjava操作符

Posted on 2017-01-21

操作符这里讲解得很仔细。

RxJava 的强大之处在于它提供了非常丰富且功能强悍的操作符，通过使用和组合这些操作符，你几乎能完成所有想完成的任务。

操作符分类

  • 创建操作符：Observable.create()、Observable.just()、Observable.from() 等等。
  • 转换操作符：observable.map()、observable.flatMap()、observable.buffer() 等等。
  • 过滤操作符：observable.filter()、observable.sample()、observable.take() 等等。
  • 组合操作符：observable.join()、observable.merge()、observable.combineLatest() 等等。
  • 错误处理操作符：observable.onErrorResumeNext()、observable.retry() 等等。
  • 功能性操作符：observable.subscribeOn()、observable.observeOn()、observable.delay() 等等。
  • 条件操作符：observable.amb()、observable.contains()、observable.skipUntil() 等等。
  • 数学运算及聚合操作符：observable.count()、observable.reduce()、observable.concat() 等等。
  • 其他：observable.toList()、observable.connect()、observable.publish() 等等。

创建操作符

常用的创建操作符还是 create、from、timer、interval。像 range、just、defer 我是真没用过。

create

create 是所有创建型操作符的「根」，其他创建型操作符最后都是通过 create 来创建 Observable 的。

from

from 是把其他类型的对象和数据类型转化成 Observable。

just

just 也是把其他类型的对象和数据类型转化成 Observable，和 from 很像，只是方法的参数有差别。

defer

defer 直到有订阅者订阅时，才通过 Observable 的工厂方法创建 Observable 并执行，所以它能保证 Observable 的状态是最新的。

timer

timer 是在延迟一段时间后发送一个 0，然后结束。

interval

interval 是每隔一段时间发送一个数字，从 0 开始，每次递增 1，一直到无穷大。

range

range 是创建一组从 n 开始、个数为 m 的连续数字。比如 range(3, 10)，就是 3、4、5……12 这 10 个数字。

repeat / repeatWhen

repeat 是对某一个 Observable 重复产生多次结果。
