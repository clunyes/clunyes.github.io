app启动优化

Posted on 2017-03-02

先量一下启动时间

用这条命令查出启动时间。Application 的初始化可以放到线程里做。

为什么不能卡在生命周期里

启动相关的这些阶段全部都在主线程执行，任何不经意的操作都可能拖慢启动速度。所以不应该在 Application 以及 Activity 的生命周期回调里做费时操作。

具体指标大概是：onCreate、onResume、onStart 等回调里花的总时间最好不要超过 400ms，否则用户从桌面点开应用图标后，会感觉到明显的卡顿。

但有些任务又不得不在 UI 显示之前执行，所以要把任务划分优先级：

  1. 优先级 1：应用启动时就开始加载。
  2. 优先级 2：首页渲染完成后再开始加载。
  3. 优先级 3：首页渲染完成后再延迟加载，用 postDelayed 的方式。
