TraceDock · AI 自动日志排查工具 在测 · AI Agent

把「连手机、翻几万行 logcat、手工配对请求与响应」这套 Android 排查流程整个自动化：选应用与设备、说一句问题 （或给一张参考图），点开始后由 AI 自己操作手机找到目标页面、触发请求、采集日志，最后产出能对回原始日志 id 的结论， 并可导出证据 ZIP。核心目标是「无感」——不让使用者先理解日志格式和采集参数。

自研锚点机制解决大日志量下的证据丢失：按已验证端点直取命中日志并提升优先级，使其在 400 条预算裁剪中不被淘汰； 动作只允许白名单内的 8 种，每次执行前强制新鲜观察，支付/删除等危险操作由本地执行器拦截，凭据一次性注入且不进模型上下文。 真机验收覆盖 3 万余条日志的完整登录链路，源码联合分析产出 5 条可逐行核对的代码引用。

Python 3.11 · FastAPI · SQLite WAL · React 19 · TypeScript · Vite · ADB · 视觉模型 · 565 后端 / 162 前端用例

ODM Pack · ODM 打包 Web 平台 AI 协作

把原来靠人记的一串手工步骤——改配置、选分支、跑预检、触发 Jenkins、回写台账——收进一条四步向导。 选完客户与交付版本，平台按「发布线匹配」推导配置仓、主工程、配网、packscript 四条分支，兼容多套历史命名； 再用 git show 直读分支上的真实配置（不切工作区），按 16 个业务分组展示并标出关键项； 预检 C0–C12 全过才放行触发 Jenkins，FAIL 直接阻断并摊开不一致明细。

后端是 Python 标准库 HTTP 服务，前端原生 HTML/CSS/JS，零第三方依赖；Jenkins 触发带 crumb， 偶发 500 自动重试且先认领队列避免重复出包，构建结果自动回写企微智能表格（按「应用 + 主干版本 + IDC」 幂等 upsert），后台线程每 12 秒兜底刷新，构建记录落盘、重启接着刷。260 个 unittest 守住回归。

实现方式是 AI 协作：仓库里的 ai/ 目录专门放给 AI 的上下文与红线（AGENTS.md、业务规则、现状与决策、审计报告）， 每次改动都按「现象 → 根因 → 改动 → 验证」留痕；AI 负责写代码，我负责定规则、卡边界和验收。

Python · 标准库 HTTP · Jenkins API · 企微智能表格 · 原生 JS · 260 单测

SolaX 光伏储能 App（Android / 多端 Hybrid）

面向户用储能、工商业储能与安装商的三套 App，共用同一套业务库支撑：40+ 模块由自研 Groovy 脚本按目录层级自动装配， 配合 Gradle build-logic 复合构建统一依赖版本与编译约定，ODM 白标通过配置开关差异化打包。 内嵌 WebView 容器承载 Vue2 / Vue3 离线包，JS Bridge 打通原生与 H5 的双向调用。

线上崩溃治理：7 天内 340 次崩溃、39 类问题、194 名受影响用户，按「发生次数 × 影响用户 × 可定位度」排优先级， 落地 6 处修复，覆盖 TransactionTooLargeException（612KB Bundle 超限）、Android 14 Insets 新 API 缺失、 Glide 持有已销毁 Activity、Gson 循环引用栈溢出等典型场景。

Kotlin 2.2 · Hilt · Retrofit · Room · 多模块组件化 · Hybrid · 崩溃治理

SolaX Cloud 移动端 H5（Vue 3）

覆盖户储、商储、安装商、VPP、远程设置与 X-Hub 六条业务线的移动端 Web 应用，支持 30 个语种； split-build 下按业务拆出 11 份 Vite 配置独立构建，配合蓝绿双环境发布，翻译文案由 Excel 脚本批量同步并做差异校验。

AI Copilot 模块：基于 SSE 的流式对话，配合 HITL 人机协同卡片（ask_user / confirm_operation）经 JS Bridge 与原生双向交互，支持参数回填、中断与恢复；同时提供 H5 蓝牙本地模式，通过 BLE 传输层与 IES2 安全码编解码， 在无网络时直连设备。

Vue 3.5 · Vite · Vant 4 · Pinia · SSE · vue-i18n · BLE
