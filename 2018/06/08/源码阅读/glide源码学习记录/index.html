glide源码学习记录

Posted on 2018-06-08

Preconditions

preconditions 用来做优雅的参数检测，以后项目里也可以用起来。

单例

泛型

源码里大量使用了泛型，以及泛型方法、泛型接口、泛型类。

  • E - Element，在集合中使用，因为集合里存放的是元素
  • T - Type，Java 类；S、U、V 分别表示第 2、3、4 个类型
  • K - Key，键
  • V - Value，值
  • N - Number，数值类型
  • ? - 通配符

分包

Glide 的包大致分为：

  • load：加载和解码
  • manager：生命周期控制
  • module
  • provider
  • request：加载图片的请求
  • signature
  • util
  • 以及默认包

分包比较简练，对外提供简单的接口，比较好懂；内部代码严谨，比较规范。

初始化

Glide 的初始化比较简单：

  1. 通过 AndroidManifest 和 @GlideModule 注解获取用户自定义的 GlideModule 配置，并调用对应的方法。
  2. 通过 GlideBuilder 构建 Glide：新建线程池；新建图片缓存池和缓存池；新建内存缓存管理器；新建默认本地缓存管理器；新建请求引擎 Engine；新建 RequestManager 检索器；新建 Glide。
  3. Glide 的构造方法里，新建模型转换器、解码器、转码器、编码器，以及生成 Glide 上下文 GlideContext。
  4. 通过 RequestManager 检索器建立生命周期监听，并建立一个 RequestManager。

完成！

into 的逻辑包含了网络请求，调用方式比较巧妙，用了桥接模式。

源码里还大量使用了注解，比如 @NonNull。大多数是编译期注解，作为编译期的辅助工具，我们自己的项目也可以用起来，能避免一些空指针。

另外还有 module 的注入。
