屏幕密度思考

Posted on 2016-12-07

像素密度以及不同屏幕

这是 Android 开发和设计都很关心的问题，我们就从 Material Design 的文档里学一下。

几个概念

  • Pixel density（像素密度）：每 inch 上的像素数。
  • Screen resolution（屏幕分辨率）：屏幕上总共的像素数。
  • 屏幕密度 dpi：也就是像素密度。为简便起见，Android 把所有屏幕密度分成六种通用密度：低、中、高、超高、超超高、超超超高。
  • Density-independent pixels（密度无关像素，dp）：A dp is equal to one physical pixel on a screen with a density of 160. 也就是说在 160dpi 的屏幕上，1dp = 1px，换算公式是 px = dp * (dpi / 160)。

react native 实践

Posted on 2016-09-14

最近接触了 React Native，发现这是未来的趋势，于是就投身进 RN 的浪潮里。

目前针对公司的产品「摩课」做 RN 化开发，项目地址是 ReactMoke。等首页功能完成，我会另开一个基于 Redux 的项目。

目前移动团队的目标也是做一个 RN 与原生交叉的 App，我们也会学习 React 的思想。不得不说，React Native 解放了移动端开发人员，不需要再频繁发版本，配合 hotfix 技术，以后可以不用做那些无谓的版本发布。

不过说一句，当时的 RN 还是不太稳定，文档不丰富，坑也有一些，不过做正常的需求还是可以满足的。
